- GNU xargs runs its command once on empty input: `… | grep … | xargs git reset -q --` with no execution logcat staged runs `git reset -q --` = every staged path unstaged. The exclude pathspec `git add -- <dir> ':(exclude)<dir>/ddp/*/logcat.txt'` does it in one command (git 2.54, scratch repo: per-run `run<i>_logcat.txt` staged, execution `logcat.txt` left out; a default pathspec `*` crosses `/`).

- The launch's address grep `10\.[0-9]*\.[0-9]*\.[0-9]*` allows empty digit runs: a decimal followed by an ellipsis ("50.10...") is a hit; compare the added lines, not the whole file.
- `assets.py` is not executable and its argument carries `edge-llm-bench-ddp-backend` (`bench`): every call is a python word plus a key word for the quiet-window hook. - zsh: `echo ======` in a chained read command is a command lookup ("===== not found"); hit again at 19:3x after r1 / r2 named it. Print separators with `printf`.
