## 罠と袋小路

- DDP splits an `args` element at its spaces: the 13-element request arrived as `argc: 18` (`--command=./litert_lm_main` and its 5 flags as separate elements, `provenance.txt`); the wrapper's join of every element after `--command=` gave the planned command (record `engineCommand` = `plan-1.json` `command`). A later wrapper keeps `--command=` last or puts no space inside an arg.
- The pulled logcats of a lab unit carry the lab network's identifiers (SSID, BSSID, MACs, private address): before staging a DDP campaign, scan the pulled logcats (perl: `SSID:`, six-pair hex MACs, dotted quads); the execution-level `logcat.txt` stays out of the commit.
- zsh: a loop variable named `path` replaces PATH (`command not found: jq / awk`) and the loop printed false "OK" lines — use another name; `echo =======` is a command lookup (r1's trap, hit again at 16:2x).
- `pgrep -fl "bench matrix"` matches other lanes' drivers and the long prompt arguments of other claude sessions (32 KB of output): match the worktree path of `run_ddp.py` instead.
- `grep` here is ugrep: a pattern with a long `.{0,60}` prefix fails ("exceeds complexity limits"); perl does it.
- After run 1 the unit stayed at Thermal Status 1 through the 600 s gate (light → light), so this 2-run job spent 720 s between run 1's end and run 2's start (`wrapper.log` epochs 1792049777 → 1792050497: cooldown 120 s + gate 600 s); the r3 estimates (8 cells × 3 runs) need that gate per run after the first.
