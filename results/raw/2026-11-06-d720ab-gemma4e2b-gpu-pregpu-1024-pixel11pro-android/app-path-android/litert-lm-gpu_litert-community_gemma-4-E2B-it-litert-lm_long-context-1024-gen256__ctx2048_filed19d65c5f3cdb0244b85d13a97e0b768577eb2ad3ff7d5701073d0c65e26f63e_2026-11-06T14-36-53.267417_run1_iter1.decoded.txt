Here are 25 distinct things on-device AI lets a phone do that a cloud model cannot:

1. **Real-time, low-latency voice commands:** On-device AI can process spoken commands instantly without needing to transmit audio data to a server first. This is crucial for features like live transcription or immediate device control.
2. **Privacy-sensitive local data processing:** Tasks like analyzing a photo taken on the device or processing a personal message can be handled entirely on the phone. This ensures that sensitive user data never leaves the local hardware.
3. **Offline functionality for core tasks:** On-device models allow for essential functions, such as basic translation or text summarization, to work even when the internet connection is unavailable. This provides reliability in areas with poor connectivity.
4. **Instantaneous personalization based on local context:** The AI can learn and adapt to the user's immediate, physical environment (like ambient noise or proximity) without needing to constantly sync with a remote database. This creates a highly personalized, immediate experience.
