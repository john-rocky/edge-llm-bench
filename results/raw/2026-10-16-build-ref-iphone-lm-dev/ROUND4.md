## 罠と袋小路

- zsh does not word-split `$CMD`: `quiet_wait.py … -- $CMD` passed the whole command line as one argv word → `FileNotFoundError: … 'ios/ddp/run_ddp_ios_lm.py --device …'` (19:01:47, the first dry run) → write the argv out, or use an array.
- The Bash tool's default timeout is 120 s: a `gtimeout 300 gtail --pid` wait without the tool's `timeout` was moved to the background (19:05) → pass `timeout` (≤ 600000 ms) for a bounded foreground wait.
- `--dry-run` prints the argv file and the campaign dir relative, but the billed run writes them into plan.json as absolute host paths (`plan()` builds them from ROOT; 3 per session) → grep plan.json before staging; written as `~` here.
- `sessions describe --full` of a running session shows neither the job's start time nor any execution: queued and running look the same until the end (session 1's job had started 3 s after creation, which only the final report shows).
- A grep for `serial` hits the engine's "serialized data" in every GPU console → count the matched text (`grep -o … | sort | uniq -c`) before replacing anything.
- Three quiet_wait started in the same second: one found the lock's flock held at its first check and waited 1 s (`window open ((lock line empty, flock held by a live holder))`).
