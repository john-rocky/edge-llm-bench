## 罠と袋小路

- Xcode 26 builds for iOS only with its own iOS platform component: with the simulator runtime gone, even `generic/platform=iOS` fails at destination resolution ("iOS 26.1 is not installed") → `xcrun simctl runtime list` and `xcrun simctl runtime match list` under the build's DEVELOPER_DIR first; `xcodebuild -downloadPlatform iOS` took 4 min for 8.32 GB.
- `-allowProvisioningUpdates` with no account in Xcode: "No Accounts", and a new id falls back to the wildcard profile, which cannot carry increased-memory-limit / extended-virtual-addressing → build with an id whose profile has them, or have a person add the account.
- A Release build for `generic/platform=iOS Simulator` links x86_64 too; CLiteRTLM's simulator slice is arm64 → `ARCHS=arm64 ONLY_ACTIVE_ARCH=YES`.
- `xcodebuild test-without-building` on a simulator installs the app again and the data container moves: a path from `simctl get_app_container` taken before the test is empty afterwards → read the container after the test (the files pushed before the test did reach the test).
- The driver's first plan called `hf_hub_download(local_files_only=False)` on the billed path; in the selftest (a stand-in cache whose refs/main is not the Hub's) that fetched the real 977 MB file into the temp dir → the plan reads the cache only; the selftest sets HF_HUB_OFFLINE=1.
- The Bash hook reads heredoc bodies: a grep pattern with "xcodebuild (build-for-testing" in a heredoc was blocked during my own window → scripts written with the Write tool and run by path.
- A new shared Swift file is invisible to committed .xcodeproj files that list sources one by one → keep shared code in a file they already compile, or regenerate (and commit) every project.
- xcodebuild's "Signing Identity" line carries the developer's real name, which can differ from the account's RealName spelling → scrub `Apple Development: <name> (` generically.
- An embedded framework's bytes differ from the xcframework's (code signing) → compare LC_UUID (`dwarfdump --uuid`), not sha256.
- LiteRT-LM v0.18.0's Package.swift excludes swift/device_tests, absent at the tag → SwiftPM prints "Invalid Exclude … File not found" (harmless).
- The round's clock ran while the session sat idle between turns (16:4x to 18:2x).
